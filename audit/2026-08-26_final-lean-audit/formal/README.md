# Formal artifacts

The executable artifacts live in `GaoLean/`.  This directory records the
mapping from the research run to those modules; it intentionally contains no
shadow copy of Lean source.

- `GaoLean/GAOARStatements.lean`: exact statement and group-order check.
- `GaoLean/GAOARLowerBound.lean`: standard lower bound (planned).
- later GAO-AR modules will be added only after their statements are frozen.
